# Lookahead demo media

The silent tour shows the real Lookahead interface using its fictional sample: the 300-perspective graph, a protocol/consent source conflict, and a five-working-day delay that moves the sample handoff from October 22 to October 29. The graph walkthrough is scripted local playback. The character, spotlight, titles, and camera motion are presentation additions.

- `lookahead-demo.gif`: looping README preview.
- `lookahead-demo.mp4`: full-resolution 1920 × 1080 video.
- App source: commit `d3e0333e4b5f5e96bf514adcf1226bd3fb759eba`.
